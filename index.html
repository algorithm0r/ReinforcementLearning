Reinforcement Learning.

A robot learns its way to the gold in a grid world. Every step costs 5; the gold pays the goal reward (100 in the 4×3 world) and a pit costs the same, and either one ends the episode and sends the robot back to the start. The blue number in each cell is its value: the cell's reward plus γ times the best expected value one move away. The robot updates the value of each cell it stands on, using what it knows of where each move leads. With Q-learning on, it instead learns a value for each of the four moves (the purple numbers) from what actually happened, with no model of the world. It moves at random with chance epsilon, which starts at 1 and is multiplied by the decay factor every so many steps; otherwise it takes the best move. On ice, a move slips to either side with the slip chance. Solve values runs value iteration to convergence.
